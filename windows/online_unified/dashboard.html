Exploratory Continuous Relative Phase (CRP) · two IMUs

Left and right shoe-pitch orientations come from raw-six-axis IMU processing, aligned to identical shared host timestamps (20 ms). The existing filtered orientation is additionally band-passed 0.35–1.25 Hz; an offline zero-phase Hilbert transform estimates each pitch oscillation phase. One combined circular right-minus-left relative phase is reported. Approx. 180° suggests anti-phase pitch oscillation for this definition, but is not an independent ground-truth or clinical score. Requires several walking cycles; results can change with frequency-band choice. Zero-phase processing is retrospective; live previews may revise.

Interpretation

Positive = toe-out, negative = toe-in on both feet. The calculated angle is relative to the marked straight reference line. It represents actual FPA only when each participant progresses parallel to that line. Securely mount both sensors in the calibrated shoe orientation; stand still at the initial taped 0° pose for five seconds. This is a research measurement, not a clinically validated estimate. The relative-foot-heading channel uses both sensor streams at the same host timestamp; it is not absolute heading or proven drift cancellation.

Severe missing samples or unstable initial pose invalidate angles. The frozen sensor filters and acquisition are unchanged. Phase 13 uses multi-evidence contact rules; B and C are provisional/review-only, not confirmed footfalls.

Six raw measured accelerometer/gyroscope channels and timestamps only. No magnetometer or sensor Euler angles. Latest live preview may be revised by full-session processing after Stop → Finalize.
